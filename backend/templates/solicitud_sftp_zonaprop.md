# Solicitud de SFTP para ZonaProp

## Asunto
Solicitud de integración SFTP — Feed XML de propiedades

## Cuerpo

```
Hola,

Somos Bienenhaus Propiedades, inmobiliaria de Córdoba.

Queremos integrarnos con ZonaProp para publicar nuestras propiedades.
Generamos un feed XML automático con nuestras propiedades en venta y alquiler.

Necesitamos acceso SFTP para subir el archivo periódicamente.
Por favor indíquennos:

1. Host SFTP
2. Puerto
3. Usuario
4. Contraseña (o clave SSH)
5. Ruta donde debe subirse el archivo

Alternativamente, si prefieren que les enviemos la URL pública del feed
para que lo indexen automáticamente, también funciona.

Quedo atento.

Saludos,
[Nombre]
Bienenhaus Propiedades
[Teléfono]
[Email]
```

## Alternativa (si no te responden)

Si no responden o no dan SFTP, **no pasa nada**. El feed ya se genera automáticamente en:

```
https://tudominio.com/api/portals/feed/zonaprop
```

Podés darles esa URL directamente. La mayoría de los portales la aceptan sin problema.
